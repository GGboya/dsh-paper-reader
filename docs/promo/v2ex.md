**标题：**

给 DeepSeek Harness 写了个论文伴读插件：AI 的回答能一键跳回 PDF 原文并高亮

**正文：**

用 AI 读论文最烦的一点：它说「作者在第 7 页提出了 X」，你还得自己翻回 PDF 找原文核对。偷懒不核对，就可能被一本正经的幻觉带沟里。

所以我写了 dsh-paper-reader —— DeepSeek Harness（dsh）的一个插件，把 agent 工作台变成论文伴读台：

**核心闭环：选中即问 → 回答带页码 → 点页码跳回 PDF 闪烁高亮原文**
（此处插 GIF：docs/demo.gif，30 秒）

几个和别的「PDF 问答」工具不太一样的点：

1. **不是一次性问答，是「老师带读」**。自带一个 agent preset：先给你定分步阅读计划（每步带页码 + 思考题），逐节陪你读、点评你的回答，然后出题、逐题批改，成绩和薄弱点记进学习档案，跨会话累积。想水过去会被抓出来打回重读（附重读页码链接）。
2. **回答必须给页码，页码必须可点**。引用定位做到了片段级——跳过去闪烁的是那句话，不是那一页。
3. **中英切换**。一键后台生成纯中文版（babeldoc），零预装——首次用时自动下载 uv + 托管 Python，不碰系统环境。
4. **不污染原界面**。装了之后 dsh 官方侧栏原样，底部多一行「📚 论文伴读」开关，点开才进入伴读模式。

技术上全部本地转录（pdf.js，纯 Node，无需 Python），检索是本地关键词 + 可选语义重排，文档不出本机。MIT 开源。

安装一行：

```
dsh plugin --profile web add @ggboy123/dsh-paper-reader
```
